Como revisar (também no fim de UIUX-DIRETRIZES.md)

  • Estrutura: menu, ações e campos existem para cada papel? (matriz §5 das diretrizes)
  • Escopo: falta ou sobra algum botão/ação sem requisito? (chips RF/CA em cada área)
  • Erros: as recusas CE-01..CE-22 aparecem com mensagem específica + ação sugerida, orientando ao estorno? (RK-4)
  • Densidade: grids densos com totais fixos no rodapé e formulários respiados com validação visível?
